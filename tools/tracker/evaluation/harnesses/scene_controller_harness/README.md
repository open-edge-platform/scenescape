# SceneController Harness

This directory contains the SceneControllerHarness implementation for running the tracker inside a Docker container.

## Files

- **scene_controller_harness.py**: Main harness implementation
- **run_tracker.py**: Script executed inside the container to run the tracker
- **__init__.py**: Module initialization

## Usage

See the parent [harnesses README](../README.md#scenecontrollerharness) for usage examples and documentation.
