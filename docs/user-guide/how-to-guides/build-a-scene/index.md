# Build a Scene

These articles will teach you how to build a scene in Scenescape.

- [Create and Configure a New Scene](./create-new-scene.md): Step-by-step guide on how to create a live scene in Scenescape.

- [Generate a Scene Map](./generate-scene-map.md): Step-by-step guide to generating a map for your scene.

- [Use Sensor Types](./use-sensor-types.md): Step-by-step guide to getting started with sensor types.

- [Visualize ROI and Sensor Areas](./visualize-regions.md): Step-by-step guide to getting started with visualizing regions.

- [Configure a Hierarchy of Scenes](./configure-hierarchy-of-scenes.md): Step-by-step guide to configuring a hierarchy of scenes.

- [Deploy Multiple Controllers on One Host](./deploy-multi-controller-on-one-host.md): Co-locate parent and child Scene Controllers on a single machine with the supported shared-ReID layout.

- [Configure Geospatial Coordinates for a Scene](./configure-geospatial-coordinates.md): Step-by-step guide for configuring geographic coordinates output in object detections.

- [Configure Geospatial Map Service API Keys](./configure-geospatial-map-service-api-keys.md): Step-by-step guide for configuring Google Maps or Mapbox API keys for geospatial mapping functionality.

- [Configure Spatial Analytics](./configure-spatial-analytics.md): Step-by-step guide to set up and use Regions of Interest (ROIs) and Tripwires.
