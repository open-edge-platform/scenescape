# Manager Service API Reference

The Manager service API is part of the shared SceneScape REST API definition.

Use the canonical [API Reference](../../api-reference.md) page for Swagger UI startup
instructions and full schema browsing.

Manager-specific endpoint groups are typically available under `/api/v1/`, including
scene, camera, sensor, calibration, and user-management workflows.
